# KnowYourLoan — Explainable Loan Intelligence System

> **Predict. Explain. Supervise.**  
> An enterprise-grade loan intelligence platform combining calibrated **CatBoost gradient boosting**, game-theoretic **SHAP explainability**, an interactive applicant assessment portal, and a dedicated **Administrator Console** for underwriting supervision.

---

## 1. Overview & Problem Statement

Traditional lending underwriting faces a fundamental tension between predictive accuracy and decision transparency. Complex nonlinear models evaluate credit risk effectively but operate as black boxes, making regulatory compliance and human oversight difficult.

**KnowYourLoan** bridges this gap:
1. **Applicant Self-Assessment:** Applicants input demographic, financial, credit history, and asset details to receive real-time credit evaluation.
2. **Transparent ML Decisioning:** Predictions are generated by a production-calibrated **CatBoost Classifier** operating at a **0.45 decision threshold** (F1-score optimized for Indian retail lending data).
3. **Exact Mathematical Explainability:** Every prediction is paired with **TreeSHAP** feature attribution, identifying the precise positive and negative drivers influencing the score.
4. **Human-in-the-Loop Governance:** An isolated **Administrator Console** (port `3001`) gives underwriters a single pane of glass to review submitted applications, analyze SHAP waterfalls, record audit notes, execute policy overrides, and export regulatory audit trails.

## 2. Key Implemented Features

### Customer Experience (Port `3000`)
- **Full Loan Application Flow:** Structured 31-input form capturing demographic, income, obligation, asset, and credit profile parameters.
- **Dynamic Obligation Engine:** Live mathematical computation of:
  - Calculated New Loan EMI ($P \cdot r \cdot (1+r)^n / ((1+r)^n - 1)$)
  - Total Monthly Debt Obligations
  - Debt-to-Income (DTI) Ratio
  - Fixed Obligation to Income Ratio (FOIR)
- **Calibrated Approval Classification:** Binary `APPROVED` / `REJECTED` outcome with raw probability percentages.
- **SHAP Factor Breakdown:** Visual breakdown of primary positive and negative factors affecting the individual's credit decision.

### Administrator Console (Port `3001`)
- **Enterprise Fintech Visual Identity:** Near-black `#070B09` aesthetic, emerald `#16A875` accents, and Space Grotesk / Inter typography.
- **Secure Authentication:** PBKDF2-HMAC-SHA256 hashed password verification with bearer session tokens (`/api/admin/login`).
- **Applications Repository:** Server-side paginated table with real-time multi-attribute filtering (prediction, review status, loan amount, probability, date range).
- **Underwriter Detail View:** Complete inspection of submitted applications, derived features, raw model probability, SHAP waterfall charts, and risk factors.
- **Review Workflow & Decision Overrides:** Update application review status (`PENDING REVIEW` $\to$ `REVIEWED`), record chronological underwriting notes, and log manual override decisions with mandatory rationale.
- **Immutable Audit Logging:** System-wide audit trail recording logins, logouts, status modifications, and policy overrides.
- **Filtered CSV Export:** Export filtered application datasets directly into standardized CSV reports.

## 5. Getting Started

### Prerequisites
- **Node.js:** v18.0.0 or later
- **Python:** 3.10, 3.11, 3.12, or 3.13
- **Git**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/luqman19-idk/KnowYourLoan.git
   cd KnowYourLoan
   ```

2. **Install Python backend dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Install frontend dependencies:**
   ```bash
   npm install
   ```

## 6. Running the Application Locally

The project consists of three services running concurrently on distinct ports:

### 1. Start the Backend API (Port 8000)
```bash
npm run backend
# Or directly:
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```
*Health check:* `http://127.0.0.1:8000/health`

### 2. Start the Customer Website (Port 3000)
```bash
npm run dev:customer
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Start the Administrator Console (Port 3001)
```bash
npm run dev:admin
```
Open [http://localhost:3001](http://localhost:3001) in your browser.

## 10. Data Persistence & Cloud Deployment Architecture

KnowYourLoan features an **intelligent dual-engine database persistence layer** ([`backend/database.py`](file:///backend/database.py)):

### Local Development (SQLite)
* **Default Engine:** Standard SQLite 3 (`know_your_loan.db`) with foreign key enforcement (`PRAGMA foreign_keys = ON;`).
* **Zero Configuration:** No external database setup required; works out of the box.
* **Test Isolation:** Integration tests automatically bind to temporary test databases (`kyl_test_*.db`), guaranteeing that local customer records are never erased.

### Production & Cloud Deployment (PostgreSQL / Supabase / Render)
* **Trigger:** Setting the `DATABASE_URL` environment variable automatically switches the engine to PostgreSQL.
* **Driver:** High-performance, binary-optimized `psycopg 3` (`psycopg[binary]>=3.1.18`).
* **Supabase / Render Integration:**
  - Fully compatible with standard PostgreSQL and Supabase transaction poolers (port 6543 / 5432).
  - Automatically handles `postgres://` to `postgresql://` URI normalization.
  - Safe, idempotent schema initialization on boot (`CREATE TABLE IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`) without table resets or data truncation.
* **Durability:** Every customer submission (`/predict`), status update, manual decision override, and audit log event is committed immediately with transactional rollback on failure.

## 11. Disclaimer & Known Limitations

- **Synthetic Training Data:** The model was trained on synthetic credit data calibrated to Indian retail borrowing distributions. It serves as an underwriting demonstration and decision-support prototype.
- **Decision Support:** Model predictions and SHAP factors provide decision assistance and algorithmic risk assessment. They do not constitute formal, legal credit sanctions or binding loan guarantees.
